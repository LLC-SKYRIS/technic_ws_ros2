# SKYRIS PDB

**SKYRIS PDB** is the power distribution board used in [Technic 4 Drone kit](assemble_4_2.md).

Board size: 35x35 mm.

> **Hint** The source files of the SKYRIS PDB board are [published](https://github.com/CopterExpress/hardware/tree/master/COEX%20PDB) under the CC BY-NC-SA license.
